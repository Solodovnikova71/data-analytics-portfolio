# DAT 325 Project Three: Data Cleaning and Integration

Academic project for Southern New Hampshire University (SNHU), DAT 325: Data Validation, Quality and Cleaning.

## Project purpose
Clean, transform and validate an acquired firm’s employee data before integrating it with company data.

## Included artifact
- [Project Three written report](DAT_325_Project_Three_Corrected%282%29.docx) — the original corrected report, preserved unchanged.

This folder is **report-only**. The associated HTML export, notebook, executable Python code and source datasets were not available for this upload and are not included.

## Work documented in the report
- Python and pandas for data cleaning and transformation.
- Median imputation and removal of records with negative or extreme numeric values or invalid categorical values.
- Splitting employee names into separate fields.
- A left merge on `Last_Name`, `First_Name` and `DOB`.
- Two histograms and a discussion of distribution patterns.

## Report-documented results and limits
The report documents shapes of 94 × 10 for the firm data, 105 × 17 for the company data and 105 × 24 for the merged data. These results were not rerun or independently reproduced for this portfolio upload. Row counts alone do not validate the accuracy or completeness of matching.
